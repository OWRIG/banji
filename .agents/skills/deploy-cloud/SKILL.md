# 云端部署

完整步骤在 `deploy/DEPLOY.md`，照着做，每一步验证通过再进行下一步。

要点：

- 先确认：服务器登录方式、域名、域名是否已 ICP 备案（中国大陆服务器必须）、有没有本地数据要迁移。
- 只运行一个 app 实例（SQLite），不要扩容。
- 部署完成后马上让老师打开网页创建账号（第一个注册的是主人，之后关闭注册），不要提前把地址发给别人。
- 不要把 `.env`、密钥、`deploy/data/` 里的数据库发到聊天里或上传到别处——里面是学生数据。
- 修改了 Dockerfile 或 compose 之后，先在本地 `docker build .` 验证能构建，再上服务器。
